# FT-10 Penghitung Estimasi Biaya Kirim Berbasis Zona & Jarak

Sumber PRD: Permintaan iterasi pengguna & Bagian 6 (BL-05, BL-06, format angka desimal)

## Tujuan
Pengguna dapat memperkirakan biaya pengiriman dari Menara Danareksa Foodcourt berdasarkan zona area Jakarta atau jarak tempuh kilometer sebelum mengirim pesanan ke WhatsApp.

## Alur
1. Pada bagian `CheckoutPreviewForm`, pengguna memilih opsi `Zona / Metode Ongkos Kirim`.
2. Jika memilih salah satu zona Jakarta (termasuk `Area Menara Danareksa`), sistem langsung menampilkan tarif estimasi zona tersebut.
3. Jika memilih `Hitung berdasarkan jarak (km)`, kolom input `Perkiraan Jarak (km)` muncul; pengguna memasukkan angka jarak (menerima koma maupun titik, misalnya `4,5` atau `4.5`).
4. Sistem menghitung estimasi ongkir dan `Estimasi Total Keseluruhan = Subtotal Menu + Estimasi Ongkos Kirim`, menampilkannya di ringkasan biaya, serta menyertakannya ke pratinjau pesan WhatsApp dan riwayat lokal.
5. Jika memilih `Konfirmasi ongkir via admin`, sistem mempertahankan perilaku awal (`Ongkos Kirim = Rp 0`, catatan `Harga belum termasuk ongkos kirim`).

## Data
- `SHIPPING_ZONES` (dari `src/config.ts`):
  - `admin-confirm`: Konfirmasi ongkir via admin (`Rp 0`)
  - `danareksa`: Area Menara Danareksa / Jl. Medan Merdeka Selatan (`Rp 0`)
  - `jakpus`: Jakarta Pusat (`Rp 15.000`)
  - `jaksel`: Jakarta Selatan (`Rp 22.000`)
  - `jakbar`: Jakarta Barat (`Rp 22.000`)
  - `jaktim`: Jakarta Timur (`Rp 28.000`)
  - `jakut`: Jakarta Utara (`Rp 28.000`)
  - `custom-distance`: Hitung berdasarkan jarak (km)
- `DISTANCE_SHIPPING_RATE` (dari `src/config.ts`): `freeUpToKm: 1`, `baseFee: 5000`, `perKmFee: 2500`, `roundTo: 1000`, `maxKm: 60`.

## Aturan dan rumus
- Jika `shippingZoneId === 'admin-confirm'`: `shippingCost = 0`, `isEstimated = false`.
- Jika `shippingZoneId` adalah zona tetap: `shippingCost = zone.flatFee`, `isEstimated = true`.
- Jika `shippingZoneId === 'custom-distance'`:
  - Ganti koma menjadi titik pada `shippingDistanceKm`, parse float.
  - Jarak valid bila `> 0` dan `<= 60` km.
  - Jika `distanceKm <= 1`: `shippingCost = 0`.
  - Jika `distanceKm > 1`: `shippingCost = Math.round((5000 + distanceKm * 2500) / 1000) * 1000`.
- `Grand_Total = Subtotal_Menu + shippingCost`.

## Input dan validasi
- `shippingZoneId`: dropdown `<select>` dengan minimal tinggi `44 px` dan ukuran teks `16 px`.
- `shippingDistanceKm`: hanya tampil bila `shippingZoneId === 'custom-distance'`, `type="text"`, `inputMode="decimal"`.
  - Error bila kosong atau bukan angka `0 < jarak <= 60`: `"Masukkan jarak antara 0,1 sampai 60 km, contoh: 4,5."`

## Tampilan dan teks
- Kotak ringkasan biaya tepat di atas pratinjau pesan menampilkan:
  - `Subtotal Menu` (`Rp ...`)
  - `Estimasi Ongkos Kirim` (`Rp ...` atau `Konfirmasi admin`)
  - `Estimasi Total Keseluruhan` (`Rp ...` dengan `tabular-nums`)
  - Keterangan bahwa tarif zona/jarak adalah estimasi awal yang tetap dikonfirmasi ulang oleh admin Dapoer AMI.
